주제 : 에너지음료광고( G-MONG )

브랜드명 : G-MONG (그몽)
타겟 : 직장인 / 회식자리
핵심 메시지: 어디서든 어떤 상황에서든 활력을 주는 에너지음료

등장인물
부장님-생김세 : 큰 덩치 째지고 작은 눈 꽉끼는 셔츠 적은 머리숯 올린머리
주인공-생김세 : 작은 덩치 얇은 몸 큰 어깨 감자처럼 동그란 얼굴 짧은 스포츠머리 째지고 작은 눈 와이셔츠
동료   -생김세 : 와이셔츠 

스토리보드

#1 문제상황(3초) 
  장소- 고깃집
  상황- 회식자리 직장 상사의 잔소리에 피곤해하는 주인공
  배경– 낮은 채도/밝기 (흐리고 답답한 분위기 연출)

부장님: 요즘에들은 말이야 옛날같지가 않어~

#2 모델등장/해결(3초) 
   장소- 고깃집밖 옆 길가
   상황- 동료의 음료수 권유
   배경- 흐린 화면에서 음료를 마시면서 점점 높아지고 밝아지는 채도/밝기 

  동료 : (어깨를 토닥여주며 격려한다) 이거 하나 마시고 힘내
 
   ( 주인공이 음료를 받고 캔을따서 마신 후 몸에서 빛이나며 날아간다 ) 
    (음료를 마신 뒤 밝아지는 분위기)

#3 마무리맨트 (3초)
장소- 길거리
상황- 거리를 힘차게 걸으며 회식자리를 주도하는 주인공
배경- 높은 채도 밝기 유지

주인공 : 부장님 2차는 그몽으로 가시죠!


#4 브랜드 로고 (1초) 
장소- 고깃집 테이블
상황- 인물들이 떠나고 테이블위에 남겨진 에너지음료 클로즈업 – 로고 등장하며 마무리
